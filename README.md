# whoisrez-repo

Sileo repo for tweaks and tools by whoisrez.

Add this source in Sileo: `https://whoisrez.github.io/whoisrez-repo/`

## Packages
- **BitLife Editor** (`com.whoisrez.bitlifeeditor`): view, back up and edit BitLife saves. Rootless, iOS 15+.

## Updating
Put new `.deb` files in `debs/`, run `./update-repo.sh`, and push.
